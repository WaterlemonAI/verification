Shared BSA/OCR/Forms/adverse queues remain single-consumer in the old environment. Provision isolated async QA stores before running mixed background flows.
4. Plan new environment certificates for `api.ai7uae.com` and `app.kycprobe.com`.    Set `CASE_MANAGER_TRAFFIC_CUTOVER=false` while the old API serves customers. The Bicep deployment keeps the existing API 5xx and adverse-source alerts on the old app; set it to `true` only with the approved DNS/traffic handoff and verify both alerts then target the new app.
5. Never delete the store or stop maintenance to roll back.
