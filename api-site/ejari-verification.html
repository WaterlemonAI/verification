Dubai Ejari
verification.

Retrieve the DLD rental certificate using its contract and DEWA numbers, or upload an Ejari PDF to compare its fields against a newly downloaded certificate.

INSTRUCTIONS TO USE

How to use this API

Submit once, then follow the returned job URLs until the result is ready.

  1. 01Get your API key

    Use a workspace API key in the Bearer header.

  2. 02Provide Ejari input

    Send the contract and DEWA numbers as JSON, or upload one PDF with a unique Idempotency-Key.

  3. 03Review the result

    Poll the result URL, compare extracted fields, and download the private DLD certificate if available.

AUTHENTICATION

Use your KYCProbe API key

Send your workspace API key as a Bearer token. Keep it on your server. Your workspace must be enabled for Dubai Ejari Verification.

Authorization: Bearer YOUR_AI7_API_KEY

REQUEST

Submit numbers or one PDF

For numbers, send JSON with contract_number (14–17 digits, starting with 0) and dewa_number (8–11 digits). For a PDF, send multipart/form-data with one ejari_file; you may also provide the two numbers as overrides. PDFs must be at most 10 MiB and 10 pages. Every submission needs a unique Idempotency-Key header (16–128 allowed characters).

contract_numberstring · required without PDF

Ejari contract number, preserving leading zeros.

dewa_numberstring · required without PDF

DEWA premise number.

ejari_filePDF · alternative input

The certificate or contract to compare with a fresh DLD download.

curl -X POST 'https://api.ai7uae.com/service/dubai_ejari_verification' \
  -H 'Authorization: Bearer YOUR_AI7_API_KEY' \
  -H 'Idempotency-Key: YOUR_UNIQUE_REQUEST_ID' \
  -H 'Content-Type: application/json' \
  -d '{"contract_number":"0120221004004205","dewa_number":"128053950"}'

Requests are asynchronous. The initial HTTP 202 response includes jobId, statusUrl, and resultUrl.

RESPONSES

Evidence with clear outcomes

verifiedDLD returned a certificate and the key OCR fields match the submitted or uploaded values.
review_requiredA certificate was retrieved, but fields differ or OCR could not establish a reliable match.
not_foundDLD explicitly returned no record for the supplied lookup details.
could_not_completeCAPTCHA, DLD, OCR, or infrastructure prevented a dependable result. This does not mean no record exists.

The result includes source, checked time, extracted fields, comparison, and certificateUrl when DLD returned a PDF. The PDF download requires the same workspace API key. Uploaded PDFs and returned certificates are encrypted in private Azure storage and expire after 30 days. The workflow sends certificate images to OpenAI for OCR and uses CapSolver for DLD’s CAPTCHA. OCR is a transcription aid; review the DLD PDF for material decisions.
