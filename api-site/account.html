AUTOMATION

Manage keys by API

Rotate the key used for a request with a server-to-server call. The response returns the replacement once and immediately invalidates the old value.

curl -X POST https://api.ai7uae.com/service/keys/self/rotate \
  -H "Authorization: Bearer YOUR_CURRENT_API_KEY"
curl https://api.ai7uae.com/service/health \
  -H "Authorization: Bearer YOUR_API_KEY"
