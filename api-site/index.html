UAE Trade Licence
All Emirates.

Verify a UAE trade licence by licence number, company name, or document through one consistent AI7 UAE endpoint.

AUTHENTICATION

One credential across every AI7 API

Send your personal AI7 API key as an HTTP Bearer token. Keep it server-side and never place it in browser code or a public repository.

Authorization: Bearer YOUR_AI7_API_KEY

REQUEST

Submit a licence lookup

Use application/json or multipart/form-data. Provide at least one primary lookup field.

license_numberstring · optional*

Trade licence number.

licence_numberstring · optional*

Alternate spelling of license number.

company_namestring · optional*

Company name in English or Arabic.

license_documentfile/base64 · optional*

Licence document as a file, base64, or data URI.

emirateenum · optional

Issuing emirate, such as dubai.

authorising_bodyenum · optional

Authority that issued the licence.

* At least one of the four primary lookup fields is required.

Accepted emirate and authorising_body values

ajmanabu_dhabiabu_dahbidubaifujairahfujirahumm_al_quwainsharjahras_al_khaimah
