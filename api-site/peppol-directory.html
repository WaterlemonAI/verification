PUBLISHED BUSINESS CARDS / GLOBAL SNAPSHOT

Peppol Directory
name search.

Search a local export of published Peppol business cards by organization name, with an optional country filter. This is directory evidence; a name match does not establish legal identity or current network participation.

POST/service/peppol_check

ON THIS PAGE

RequestResponsesCountries

REQUEST

Search a published name

Send a workspace API key in the Bearer header and a JSON body with name (3–200 searchable characters). Optional country is a two-letter ISO code such as AE; omit it for a global search. The API normalizes the name before looking it up in the local export. No live Peppol Directory call is made.

curl -X POST 'https://api.ai7uae.com/service/peppol_check' \
  -H 'Authorization: Bearer YOUR_AI7_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"name":"Example Trading LLC","country":"AE"}'

RESPONSES

Snapshot search result

matches can contain zero to ten business cards. Each card can contain multiple document types and business entities. The exported card fields depend on what the publisher supplied. not_found means no matching name was found in this snapshot; it does not prove the organization is absent from Peppol.

Status codes

200Search completed; inspect status, matches, and snapshot age
400Invalid name or country input
401Missing or invalid API key
402Insufficient prepaid credit
403Peppol module unavailable to this workspace; error body has status and error
429Rate limit reached
503Index unavailable; response status is unavailable and matches is empty

COUNTRY CATALOG

Check available country codes

GET /service/peppol_check/countries returns the snapshot time, total card count, and a countries array. Each item contains a two-letter code and its count. The list may include multiple countries and depends on the loaded export. HTTP 503 with status: unavailable and an empty list means the index is not ready.
