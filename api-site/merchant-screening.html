REQUEST

Screen a public merchant website

website_urlHTTPS URI · required

Public merchant website. Credentials, IP literals, private addresses, non-HTTPS URLs, and non-standard ports are rejected.

country_codeISO alpha-2 · required

Two-letter country code used to select the merchant policy baseline.

declared_merchant_namestring · optional

Merchant name supplied by the applicant or onboarding system.

declared_mccfour digits · optional

Declared merchant category code for comparison with product evidence.

max_pagesinteger · optional

Maximum same-origin pages to collect, from 1 to 20. Default: 12.

high_risk_threshold_percentnumber · optional

Scores at or above this percentage are High Risk. Default: 60.

review_threshold_percentnumber · optional

Scores from this percentage up to the High Risk boundary require Review. Lower scores are Safe. Default: 25.

get_pdfboolean · optional

When true, creates a permanent audit PDF with actual rendered screenshots, service description, processing log, findings, evidence, and the full result attachments.

customer_logo_urlHTTPS URI · optional

Public PNG or JPEG placed on the requested PDF report.

METHODOLOGY

            
Bounded collection with explicit limits

            
The collector follows only public HTTPS destinations, validates DNS before each request, pins the validated address, rechecks every redirect, respects robots.txt, stays on the final merchant origin, and caps pages, bytes, redirects, and time. Candidate MCCs and keyword signals are review aids—not card-network classifications or automatic decline decisions. A missing enrichment result is shown as unavailable and never converted into a negative match.
