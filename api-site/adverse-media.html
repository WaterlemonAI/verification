RESPONSE

            
Customer-ready evidence

            
Every retained result includes its original URL, evidence excerpt, risk category, legal stage, and combined risk score. Internal search, model, cost, and scoring diagnostics are never returned.

            
With deep research and a callback URL, the initial response is HTTP 202. The final callback is sent once after bounded processing, with event_id, screening_id, completed_at, and data. Verify x-ai7-signature against the raw body and deduplicate delivery retries using x-ai7-event-id. If a source remains unavailable, data.status is partial and data.summary.decision_eligible is false.

METHODOLOGY

            
Designed for review, not automated guilt decisions

            
The engine normalizes names and aliases, generates tightly constrained name transliterations for selected non-English languages, and performs a bounded identity-resolution pass for multi-part individual names to discover explicit aliases and associated organizations. It searches current and archived indexes with controlled retries, removes duplicate URLs, classifies adverse-event terms, and ranks evidence. The taxonomy distinguishes corporate misconduct from founder/leadership disputes, workforce restructuring, and financial distress; a layoff or founder split is a reviewable event, not automatically a fraud allegation. Search+ reserves part of the fixed 12-query guardrail for explicit publisher-domain batches, prioritises requested countries and high-value editorial categories, and reports the successful and incomplete publisher lists. A successful site-restricted index query proves the query ran; it does not prove the index contained every article published by that outlet. Partial individual-name matches are rejected before classification, while only high-confidence evidence mismatches can suppress a candidate. Any exhausted source or required classification failure makes the run partial, returns an inconclusive outcome, blocks decision eligibility, and requires manual review. A media result is a review lead—not proof of wrongdoing.
