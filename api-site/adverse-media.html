METHODOLOGY

            
Designed for review, not automated guilt decisions

            
The engine normalizes names and aliases, searches current and archived indexes, removes duplicate URLs, requires an entity-name match, classifies adverse-event terms, and ranks evidence. The most relevant candidates receive a bounded AI review when configured; deterministic results remain available if that review is unavailable. A media result is a review lead—not proof of wrongdoing. Qualified human review remains required before taking action.
