INTERPRETATION

Three different coverage measures

Available scope

The search channels, language options and publisher selection pool configured for this API.

Run scope

The languages, source queries, publisher domains and archive path attempted for one screening.

Returned evidence

The indexed articles and pages found, deduplicated, classified and retained in the result.

A domain in the catalog is eligible for selection; it was searched only if it appears in coverage.search_plus.publishers_screened for that run. A completed indexed query does not establish that every article from that domain was indexed. “No Adverse Media Found” means no qualifying adverse evidence was identified within the completed search scope.

LOOKBACK AND CONTINUITY

Historical coverage is recorded, not assumed

Without dates, the local-index coverage check uses a rolling 72-hour requested window. It is treated as complete only when its watermark spans the requested period and its latest indexed time is within the 36-hour freshness allowance. A requested earlier period, a stale or missing watermark, or an incomplete local read triggers the hosted historical fallback.

Local indexHistorical fallbackReported outcome
Covers the requested window and is freshNot neededLocal archive can complete; response reports its exact watermark.
Incomplete, stale or unavailableCompletesHistorical channel can complete through fallback; response identifies the fallback path.
Incomplete, stale or unavailableFails after retriesHistorical coverage is incomplete. The API cannot issue a clean completed screening.

The fallback searches up to one year and returns no more than 50 newest matching records. A date filter does not turn this into exhaustive one-year retrieval: older matching records can be displaced by newer matches before filtering. Requests older than one year have no historical completeness claim. The exact archive origin, watermark and source status in the response supersede any static description here.

LANGUAGE SCOPE

17 configured languages

Request up to five languages. English and Arabic are the default. The response distinguishes requested languages from those actually queried; an omitted requested language blocks a completed search decision.

Indonesian search terms are submitted with a broader index-language preference because a dedicated Indonesian filter is unavailable. Names are not automatically transliterated; provide alternate-script spellings as aliases. A configured language is a query capability, not a guarantee that every publisher in that language is indexed.

FAIL CLOSED

Incomplete search never becomes a clean result

Search coverage and classification are separate. A source may complete while classification remains uncertain; that is an inconclusive profile, even though the search itself completed.

Condition after retriesStandard Adverse Media routeDedicated Search+ route
Required searches and classification completeCompleted result; risk outcome follows classified adverse evidence.Completed result; risk outcome follows classified adverse evidence.
Historical fallback fails while local index does not cover the requested windowPartial, decision-ineligible result; no clean conclusion.HTTP 503 SEARCH_INCOMPLETE; no screening report issued.
Another required search or requested language is missingPartial, decision-ineligible result, or an error when all search channels fail.HTTP 503 SEARCH_INCOMPLETE; no screening report issued.
Search completes but classification is unavailable or uncertainPartial, inconclusive profile; evidence remains visible where possible.Unavailable classification returns HTTP 503; uncertain classification can return a partial, review-required result.

The one-year historical fallback is a bounded search path, not a guarantee that a full year remains available if it fails. If both historical paths cannot establish the requested coverage, the API reports that gap explicitly. A completed run with neutral or positive general-news mentions and no confirmed adverse evidence can return No Adverse Media Found; a partial run cannot.
