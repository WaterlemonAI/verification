ASYNC WORKFLOW

            
Submit, receive a callback, or poll

            
The submit endpoint returns 202 Accepted with an analysisId, statusUrl, and resultUrl. When callback_url is supplied, AI7 also returns a one-time signing secret and posts the terminal result to that public HTTPS endpoint. Polling remains available as a fallback.

            
Verify the exact callback body with HMAC-SHA256 from x-ai7-signature, and de-duplicate retries using x-ai7-delivery-id. Callbacks are at-least-once: your endpoint should return HTTP 2xx only after safely accepting the event. Partial and failed results remain ineligible regardless of callback delivery.

            
Source documents, job state, and artifacts are tenant-isolated and encrypted. Azure Document Intelligence uses managed identity; no supplier access key is exposed to clients or stored in the application.
