INSTRUCTIONS TO USE

How to use this API

Start here, then use the detailed request and response reference below.

  1. 01Get your API key

    Use a workspace API key in the Bearer header.

  2. 02Upload a document

    Send a file and a unique Idempotency-Key in a multipart POST.

  3. 03Poll and review

    Follow the returned status and result URLs; check fields, evidence, and review flags.

AUTHENTICATION

Use your KYCProbe API key

Send the API key as a Bearer token. Keep the key on your server. Your workspace must be enabled for this module.

Authorization: Bearer YOUR_AI7_API_KEY

REQUEST

Upload and extract

Send multipart/form-data with one required file. Emirates ID accepts one optional additional_file for the second side. PDF, PNG and JPEG are supported. The combined upload limit is 25 MiB; the page limit appears below.

Every submission requires a unique Idempotency-Key header (16–128 allowed characters). Repeating the same key and exact files returns the original job without charging again. The API returns HTTP 202 while processing; poll the status and result URLs.

DATA HANDLING
Private, time-limited retention
Uploaded files, OCR text, structured result, and any image crops are encrypted in private cloud storage and retained for 30 days. Photo and signature crops, where available, use five-minute signed download links. The result can also be fetched with your API key during retention. The input document is treated as untrusted content, and missing information is left empty rather than invented.
