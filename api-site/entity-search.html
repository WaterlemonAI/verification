AUTHENTICATION

Use your existing AI7 credential

Send your personal AI7 API key as an HTTP Bearer token. The same credential works across every API enabled for your account.

Authorization: Bearer YOUR_AI7_API_KEY

REQUEST

Search across all checks

Send application/json. AI7 passes the documented field names and values through unchanged.

namestring · required

Name of the entity.

typeenum · required

Individual, Organization, Aircraft, Vessel, or Goods.

aliasstring[] · optional

Aliases or alternate names.

countrystring · required key

Associated country. Send an empty string when unknown.

citystring · optional

Associated city.

statestring · optional

Associated state or province.

designationstring · optional

Known designation or position.

genderstring · required key

Known gender. Send an empty string when unknown.

dobyyyy/MM/dd · required key

Known date of birth. Send an empty string when unknown.

identifierobject[] · optional

Known identifiers using type and value.

watchlist_list_idsinteger[] · optional

Watchlist list IDs used to filter results.

sanction_list_idsinteger[] · optional

Sanctions list IDs used to filter results.

search_typestring[] · required

Risk datasets to search.

fields_weightageobject[] · required

Field weights; the values must total exactly 1.

fuzzinessnumber · required

Minimum matching threshold from 0 to 1. A value of 0 does not make every returned score 0; profiles retain their own supplier match scores. The wrapper returns the submitted value in the x-ai7-submitted-fuzziness response header.

event_stage_scoreinteger · optional

APC event stage, 1–4. Default 1.

sentiment_confidencenumber · optional

APC negative-sentiment threshold, 0–1.

apc_durationinteger · conditional

Past days to retrieve; required for APC-only search.

apc_countriesstring · optional

APC country filter. Default global.

apc_sort_byenum · optional

relevance or date.

APC must be searched alone. ER-APC must be combined with at least one of PEP, sanctions, or watchlists.
